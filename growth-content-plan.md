# Iconia AI Growth Content Plan

This file defines the repeatable content system for growing organic traffic without using the owner's personal social accounts.

## Priority keyword clusters

- AI game icon generator
- game icon maker AI
- clan icon maker AI
- guild icon generator
- Discord icon maker AI
- anime game icon generator
- gaming profile picture AI
- custom gamer avatar AI
- team logo maker AI
- gaming clan logo AI

## Content rules

1. Create genuinely useful pages for a specific search intent; do not publish thin keyword-only pages.
2. Every page should explain the use case, show examples, link naturally to Iconia AI, and include an FAQ.
3. Avoid claims that imply guaranteed results or guaranteed income.
4. Do not copy competitors or copyrighted text.
5. Review generated content before publishing when platform/API automation does not support safe automatic publication.

## Weekly production loop

- Discover new search intents from Search Console, site analytics, and user prompts.
- Rank opportunities by relevance, estimated demand, and ability to convert to an Iconia AI session.
- Draft the best page for the top opportunity.
- Add the URL to sitemap.xml.
- Track landing page views, generator starts, pricing clicks, and purchases.
- Retire or improve pages that receive impressions but little engagement.

## Conversion targets

The primary funnel is:

Search/Social discovery -> helpful landing page -> Iconia AI generator -> generation -> pricing -> purchase.

## Privacy separation

Do not use or connect the owner's personal X, Instagram, TikTok, or other personal social accounts. Any future social distribution should use dedicated Iconia AI brand accounts and only after the owner creates/authorizes them.
